# @slotted/theme

The Slotted theme contract: token names, cascade layer order, seeds, the `defineTheme` runtime and the `slotted-build-theme` command that compiles a theme to a stylesheet.

This package is a `0.x` beta. Its public API changes between beta releases without deprecation.

An application installs it as a peer dependency of `@slotted/react` or `@slotted/angular`. A custom theme is built against `@slotted/theme/contract.json` and checked with `@slotted/theme/conformance` ([theming](https://github.com/andrelopes-code/slotted/blob/main/docs/decisions/0004-theming-architecture.md)).
