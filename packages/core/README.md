# @slotted/core

Framework-independent part of Slotted: collections, formatting, dates, currency, i18n catalogs and the per-family behavior that `@slotted/react` and `@slotted/angular` bind to their frameworks.

This package is a `0.x` beta. Its public API changes between beta releases without deprecation.

An application installs it as a peer dependency of `@slotted/react` or `@slotted/angular`. `echarts` `^6.1.0` is an optional peer dependency, required only by `@slotted/core/chart-echarts`.
