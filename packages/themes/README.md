# @slotted/themes

Prebuilt Slotted themes.

This package is a `0.x` beta. Its public API changes between beta releases without deprecation.

```css
@layer slotted, app;
@import '@slotted/themes/default.css';
```

`@slotted/themes/default` exports the same theme as a module for `defineTheme` and `extendTheme` from `@slotted/theme`.
