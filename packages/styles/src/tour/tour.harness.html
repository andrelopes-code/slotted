Automatisierungsregelverwaltungsoberfläche

Rules run when a report changes. Each rule has a trigger, a condition and one or more actions, and runs in the order it appears in the list.

A rule that fails stops the rules after it, and the report shows which one failed and why. Rules you pause keep their history.

Owners and editors can add rules. Viewers see the list and the history, and cannot change either.
