# @slotted/styles

Per-family stylesheets and component token declarations of Slotted.

This package is a `0.x` beta. Its public API changes between beta releases without deprecation.

`@slotted/react` bundles these stylesheets into `@slotted/react/styles.css`, and `@slotted/angular` bundles them into its components. An application that uses either binding does not install this package.
