---
title: Introduction
description: Slotted is a component library with one design contract and idiomatic bindings for React and Angular.
order: 1
---

Slotted ships one stylesheet per component family and one binding per framework. Both bindings render the same DOM: the same `data-ui` attributes, the same parts, the same ARIA wiring. The stylesheet selects that DOM, so a component looks and behaves the same in React and in Angular.

## Packages

| Package            | Contents                                                                  |
| ------------------ | ------------------------------------------------------------------------- |
| `@slotted/theme`   | Design tokens and the cascade layer order                                 |
| `@slotted/themes`  | The default theme: light, dark and high-contrast schemes, three densities |
| `@slotted/styles`  | One stylesheet per component family                                       |
| `@slotted/core`    | Framework-independent behavior shared by the bindings                     |
| `@slotted/react`   | The React binding                                                         |
| `@slotted/angular` | The Angular binding, one secondary entry point per family                 |
