## Separating two regions

A divider marks the boundary between two regions of content with one line. The plain rule is an `hr`, which already carries the separator role, so a screen reader announces the boundary without any attribute from the component. Use it where the content on each side is of the same kind, as in the example above. To space two blocks without a line, set the `gap` of a `Stack` instead.

## Orientation

`orientation` sets the direction of the rule: `horizontal`, the default, or `vertical`. A horizontal rule takes the width of its container. A vertical rule stretches to the height of its row, whatever the alignment of the other items. A vertical rule sets `aria-orientation="vertical"`, because a separator is horizontal unless it says otherwise.

## Label

`label` interrupts the rule with a short text. A labelled rule is a `div`, because an `hr` takes no content, and it writes `role="separator"`. React renders that element; in Angular, `slDivider` goes on a `div` you write. The text also becomes the accessible name through `aria-label`: the separator role makes its children presentational, so the visible text alone would leave the rule announced as empty. An `aria-label` of your own replaces it.

<Example name="label" />

## Label position

`align` places the label along the rule: `start`, `center` or `end`, in logical terms, so `start` is the right end in a right-to-left layout. The default is `center`. A label at one end keeps one half of the rule. It applies only to a rule that has a `label`.

## Vertical label

A vertical rule takes a label too. The text sits between two halves of the rule, and `align` places it along the height of the rule.

## Inset

`inset` stops the rule short of both ends of its container. The margin is the inline padding of a control, so a rule inside a list of rows lines up with their text. It applies to both orientations: a horizontal rule gains margin at its inline ends, a vertical rule at its block ends. Each card below holds rows of buttons: in the second, the rule starts where the text of the rows starts.

## Decorative

`decorative` removes the rule from the accessibility tree: the element takes `role="none"`, so a screen reader announces no separator. Use it when the line groups content visually and a listener loses nothing by not hearing it. A rule without `decorative` is announced as a separator, and a labelled one is announced with its label as the name. A decorative labelled rule has no name; its text is read in document order, like any other text.

## Between values

A row of figures separated by vertical rules is the common use of a vertical divider. The rules are decorative because the figures already carry their own labels. Each rule is as tall as the row.
