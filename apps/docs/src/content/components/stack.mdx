## Gap

`gap` sets the separation between children as a step on the space scale, from `0` for none to `12`. The default is `6`. Each column below holds the same three badges at one step. A stack lays out one column; use `Inline` for a row.

<Example name="gap" wide />

## Alignment

`align` positions children across the column, along the inline axis: `start`, `center` or `end` give each child its own width and place it on that edge. Without `align`, children stretch to the width of the column, as the last card shows. A button directly inside a stack stretches the same way, so a row of actions belongs in an `Inline`.

<Example name="align" />

## Justification

`justify` positions children along the column and distributes the free space between them: `start`, `center`, `end`, `between`, `around` or `evenly`. It moves nothing until the stack is taller than its content, so each stack here has a block size of 12rem. In a page shell the stack takes that height from its container.

<Example name="justify" wide />

## Sections and lines

A stack inside a stack gives each level its own gap: a wide gap separates the sections and a narrow gap separates the lines inside one. The outer stack here uses `8` and each inner stack uses `2`.

## Another element

A stack paints nothing and claims no semantics, so you choose the element. In React, `render` replaces the root element. In Angular, the `slStack` attribute goes on the element itself. Fields that are sent together stand in a `form`, so Enter in a field submits them. A `ul` keeps the bullets and the indentation the browser gives it: a stack does not reset them.
